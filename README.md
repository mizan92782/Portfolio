# Mizanur Rahman — Portfolio

Personal developer portfolio website built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no build tools — just clean, fast, and fully responsive.

## Live Sections

- **Hero** — Intro with animated typed text, profile photo, social links, and resume download
- **About** — Bio, location, availability, and freelance status
- **Experience** — Work history and freelance projects with tabbed timeline
- **Skills** — Categorized tech stack (Frontend, Backend, Database & Cloud, Infra, Monitoring) + tools grid
- **Projects** — 6 featured projects with live demo and GitHub links
- **Education** — Academic background
- **Contact** — Contact form powered by Formspree

## Tech

- Pure HTML5, CSS3, Vanilla JavaScript
- Google Fonts — Outfit + JetBrains Mono
- Font Awesome 6 — icons
- Devicons — tech stack icons
- Formspree — contact form backend

## Features

- Custom animated cursor
- Typed text animation in hero
- Scroll-triggered reveal animations (IntersectionObserver)
- Sticky navbar with active section highlighting
- Responsive mobile menu (hamburger)
- Dark theme with green accent (`#0da80f`)
- Spinning ring profile photo frame
- Floating badges
- Staggered card animations

## Structure

```
index.html        # All sections and JS
style.css         # All styles and responsive breakpoints
profile.jpg       # Profile photo
Resume_MD_Mizanur_Rahman.pdf   # Downloadable resume
```

## Run Locally

No build step needed — just open in a browser:

```bash
git clone git@github.com:mizan92782/Portfolio.git
cd Portfolio
open index.html   # or just double-click the file
```
